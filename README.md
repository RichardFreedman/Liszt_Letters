# Liszt_Letters

## Setup

1. Install the requirements: `pip install -r requirements.txt`
2. Copy `pipeline.env.example` to `pipeline.env` and paste your API keys into it.
   `pipeline.env` is ignored by git, so your keys stay on your computer.
3. Run the notebooks in order: `1_Transcription`, `2_Chroma_DB_Builder`, `3_RAG_Query`.
